1. Wprowadzenie i Składnia

1.1. Historia i cele projektowe C#

  • Twórca: **Anders Hejlsberg** (znany z Delphi/Turbo Pascal).
  • **Debiut:** Rok 2000, jako część platformy **.NET Framework**.
  • **Cel:** Stworzenie nowoczesnego, **obiektowego** i bezpiecznego (typowo) języka. Miał łączyć efektywność C++ z produktywnością Javy.
  • **Nazwa:** "C-Sharp" sugeruje ewolucję C++, jest podniesieniem o pół tonu nuty C (ang. sharp).
  • Obecnie rozwijany jako **Open Source** (od .NET Core) i zgodny ze standardami ECMA/ISO.

1.2. Struktura programu (`namespace`, `using`, `Main`)

  • **`using System;`**: Importuje przestrzeń nazw, dając dostęp do gotowych klas i funkcji (np. `Console`).
  • **`namespace`**: Organizuje kod, zapobiegając kolizjom nazw. Każda aplikacja jest zbiorem przestrzeni nazw.
  • **`public class Program`**: Klasa będąca kontenerem dla metod.
  • **`public static void Main(string[] args)`**: **Punkt startowy** każdej aplikacji konsolowej.
							
				using System;

				namespace MojaPrezentacja
				{
					public class Program
					{
						public static void Main(string[] args)
						{
							// Kod startowy programu
							Console.WriteLine("Witaj w C#!"); 
						}
					}
				}
